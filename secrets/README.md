# secrets/

**שים כאן את קובץ ה‑JSON של ה‑service account, בשם:**

```
secrets/vertex-sa.json
```

בדיוק כפי שגוגל נתנה לך אותו — בלי לערוך, בלי למחוק שדות, עם ה‑`private_key` המלא.
אחר כך פשוט:

```bash
npm run check
```

הכלי מוצא את הקובץ לבד — בלי דגלים ובלי משתני סביבה.

## הערות

- אם קראת לקובץ בשם אחר, זה עדיין יעבוד כל עוד יש כאן **קובץ JSON אחד בלבד**.
  אם יש כמה, הכלי יסרב לנחש ויבקש ממך `--key secrets/<שם>.json`.
- כל התוכן של התיקייה הזאת ב‑`.gitignore` חוץ מהקובץ הזה. שום מפתח לא נכנס לגיט.
- ה‑`project_id` וה‑region נלקחים מהקובץ עצמו, אז אין מה להגדיר בנוסף.
  לעקוף: `--project <id>` או `--region <r>`.
